# Зертханалық сабақ №7. Суреттерді фондық режимде жүктеу

`Image.network` + жүктелу индикаторы (`frameBuilder` + `loadingBuilder`), `GridView` ішінде 9 сурет, «Жаңа суреттер жүктеу» батырмасы жаңа кездейсоқ суреттерді шақырады (picsum.photos).

## Іске қосу

```bash
flutter pub get

flutter test
flutter run            # эмулятор / құрылғы
```
