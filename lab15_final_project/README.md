# Зертханалық сабақ №15. Жобаның финалдық тексерісі

4–9 және 14-зертханалардың функционалын біріктіретін қосымша: логин/тақырып, ToDo, API, суреттер, геолокация, камера/жад, push. «Финалдық тексеріс» экраны логин, CRUD, API, GPS, камера/жад рұқсаттары, Firebase және Release режимін автоматты тексереді. Release APK: `../release/lab15-final-release.apk`.

Нәтиже: **8 / 8** (release APK, Android эмуляторы). Firebase: жеке жоба, қосымша `kz.labs.lab15_final_project`; `google-services.json` `android/app/` ішінде.

## Іске қосу

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # эмулятор / құрылғы
```
