# Зертханалық сабақ №13. Flutter-де қарапайым кроссплатформалық қосымша

Counter-үлгі: тақырып «Flutter Demo», мәтін «Сәлем, Flutter!», «Басыңыз» батырмасы және FAB санауышты арттырады. Бір код екі платформада тексерілді: Android эмуляторы және Chrome (web). iOS қалтасы (`ios/`) жобада бар, бірақ Xcode орнатылмағандықтан iOS-та іске қосылған жоқ.

## Іске қосу

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # эмулятор / құрылғы
```
