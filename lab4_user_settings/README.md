# Зертханалық сабақ №4. Пайдаланушы параметрлерін сақтау (логин / тақырып)

App State (`userName`, `isDarkMode`) `ChangeNotifier` + `shared_preferences`. Login Page → Profile Page, «Dark Mode қосу» батырмасы тақырыпты ауыстырады, мәндер қосымша қайта ашылғанда сақталады.

## Іске қосу

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # эмулятор / құрылғы
```
