# Зертханалық сабақ №9. Рұқсаттармен жұмыс (камера, жад)

`permission_handler` + `image_picker`: «Камераны ашу» (Take Photo) және «Жадтан сурет таңдау» (Photo Library). Рұқсат берілмесе — «Рұқсат берілмеді!» Snackbar.

> `permission_handler` 12.0.1 қолданылады: 13.x нұсқасы Android SDK 37 талап етеді, ал орнатылған SDK — 36.

## Іске қосу

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # эмулятор / құрылғы
```
