# Зертханалық сабақ №5. CRUD-қосымша: тапсырмалар тізімі (ToDo)

Create / Read / Update (isDone + атауын өзгерту) / Delete. Деректер `shared_preferences` (Local State) ішінде JSON ретінде сақталады. Әдістемедегі Firestore орнына Local State алынды (әдістеме екеуін де рұқсат етеді); `TaskRepository` интерфейсі арқылы Firestore-ға ауыстыруға болады.

## Іске қосу

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # эмулятор / құрылғы
```
