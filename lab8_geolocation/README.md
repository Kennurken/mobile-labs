# Зертханалық сабақ №8. Геолокация: экранда координаттарды шығару

`geolocator`: рұқсат сұрау, `Latitude` / `Longitude` шығару. Эмуляторда координата `adb emu geo fix 71.4704 51.1605` (Астана) командасымен берілген.

## Іске қосу

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # эмулятор / құрылғы
```
