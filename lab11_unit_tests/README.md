# Зертханалық сабақ №11. Қосымшаға unit-тест жазу

Калькулятор (`add`, `subtract`, `multiply`, `divide`) және ToDo бизнес-логикасы (`TodoList`). 11 тест: оң/теріс сандар, нөлге көбейту, нөлге бөлу қатесі, бос атауды қабылдамау, widget-тест. Іске қосу: `flutter test`.

## Іске қосу

```bash
flutter pub get
flutter analyze
flutter test
flutter run            # эмулятор / құрылғы
```
